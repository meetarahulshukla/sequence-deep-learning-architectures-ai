## 📂 Deep Dive: The Transformer Architecture

The repository begins with the foundational **Transformer** architecture introduced in the landmark paper *"Attention Is All You Need"* (Vaswani et al., 2017). Unlike traditional sequential networks, Transformers discard recurrences entirely in favor of global attention mechanisms.

### The 9-Step Training Pipeline

```text
[1. Input Sentence] -> "El gato duerme"
                             │
                             ▼
[2. Embeddings]     -> Converts tokens into semantic continuous vectors
                             │
                             ▼
[3. Positional]     -> Injects unique mathematical position tags
                             │
                             ▼
[4 & 5. Encoder]    -> Maps complex self-attention dependencies simultaneously
                             │
                             ▼ (Sends contextual representation to Decoder)
                             │
[6 & 7. Decoder]    -> Generates target autoregressively (uses future-masking)
                             │
                             ▼
[8 & 9. Optimization]-> Calculates Cross-Entropy Loss ➔ Backprop ➔ Adam Update
```

### Key Training Principles Breakdown

1. **Supervised Learning:** The model is trained using a supervised paradigm, mapping source input sequences directly to ground-truth target sequences (e.g., machine translation).
2. **Input Representation:** Text sequences are tokenized and transformed into continuous embedding representations to capture initial semantic meaning.
3. **Positional Encoding:** Because attention processes all tokens simultaneously, unique positional vectors are added to the token embeddings to explicitly maintain sequence order.
4. **Encoder-Decoder Architecture:** The Encoder processes the source data into a contextual representation map, while the Decoder consumes that map to generate the final sequence output.
5. **Self-Attention Mechanism:** Deployed in both modules, this allows tokens to directly communicate with and dynamically weight all other tokens across the entire sequence.
6. **Cross-Attention Mechanism:** Positioned inside the Decoder, this enables the generation steps to focus selectively on highly relevant features generated by the Encoder.
7. **Masking in Decoding:** During training, the Decoder's self-attention utilizes a causal mask to block future positions, preventing the model from "peeking" ahead at answers.
8. **Loss Calculation:** Predicted target probabilities are evaluated against the true tokens using a loss metric (typically cross-entropy).
9. **Backpropagation and Optimization:** Gradients are calculated backward through the network, and optimized using algorithms like Adam to continuously update parameters.

## 📊 Architectural Feature Comparison

| Paradigm | Processing Style | Computational Complexity | Context Window Limitations | Primary Bottleneck |
| :--- | :--- | :--- | :--- | :--- |
| **RNN / LSTM** | Sequential ($O(N)$) | $O(N)$ linear step complexity | Prone to vanishing gradients (forgets history) | Cannot parallelize training efficiently |
| **Transformer**| Parallel ($O(1)$) | $O(N^2)$ quadratic complexity | Heavy memory footprint scaling with length | Quadratic VRAM bottleneck at scale |
| **SSM / Mamba**| Selective Sequential | $O(N)$ linear step scaling | Maintains hardware-efficient long contexts | Trade-offs in granular factual retrieval |
